# WORLD QUIZ

1,230개의 세계 상식 문제로 이루어진 퀴즈 웹앱입니다. **한 번 화면에 나온 문제는 같은 모드에서 다시 나오지 않습니다.** 백엔드 없이 정적 호스팅(GitHub Pages)에서 동작하고, 오프라인 플레이와 홈 화면 설치(PWA)를 지원합니다.

- 일반 상식 1,000문제 (`G0001`~`G1000`)
- 의외의 상식 200문제 (`U0001`~`U0200`)
- 초고난도 30문제 (`X0001`~`X0030`)

## 주요 기능

- **중복 출제 방지**: 문제가 화면에 처음 표시되는 순간 ID를 IndexedDB 출제 기록에 저장합니다. 새 게임은 출제 기록에 없는 문제만 Fisher–Yates 셔플(crypto 난수, 거부 샘플링)로 뽑습니다. 정답·오답 모두 출제한 문제로 처리하며, 새로고침이나 앱 종료 후에도 유지됩니다.
- 모드의 문제를 모두 푼 경우에만 **출제 기록 초기화 / 오답 복습 / 다른 모드** 중 선택할 수 있습니다.
- 게임 설정: 10·20·30문제, 남은 문제 모두, (초고난도) 5·10문제, 시간제한 ON/OFF. 남은 문제가 부족하면 남은 개수를 표시하고 그만큼만 출제합니다.
- 4지선다, 보기 순서 매번 무작위, 답 수정 불가, 정답/오답을 색·아이콘·텍스트로 함께 표시, 해설과 출처 링크.
- 진행 중인 게임 자동 저장과 이어하기 (출제 기록과 별도 저장소).
- 결과 화면: 정답·오답 수, 정답률, 문제별 결과, 분야별 정답률, 약한 분야, 누적 기록, 틀린 문제 다시 보기.
- 오답 노트: 자동 저장, 모드·분야 필터, 복습 퀴즈, 틀린/맞힌 횟수, 반복 오답 표시. 복습은 출제 기록에 영향을 주지 않습니다.
- 통계: 누적 플레이, 누적 출제 수, 누적 정답률, 최고 연속 정답, 모드별 진행률, 분야별 숙련도, 최근 10게임, 마지막 플레이 날짜.
- 북마크, 문제 신고(기기에 저장 + GitHub 이슈로 보내기), 키보드 1~4 / Enter, 글자 크기 조절, 라이트/다크 모드, 모션 줄이기, 기록 JSON 내보내기·가져오기(병합).

## 구조

```
index.html, css/app.css      화면
js/app.js                    화면·내비게이션
js/engine.js                 셔플·출제·채점·집계 (DOM 독립, 테스트 대상)
js/store.js                  IndexedDB (seen / qstats / games / session / bookmarks / reports / meta)
data/{general,surprising,expert}.json, data/meta.json   모드별 문제 데이터 (필요한 모드만 불러옴)
sw.js, manifest.webmanifest  오프라인·설치
scripts/import-source.mjs    원본 문항 파일 → data/*.json 변환
scripts/validate.mjs         데이터 자동 검증 → VALIDATION.md
tests/engine.test.mjs        중복 출제 방지·채점 테스트
```

## 문제 데이터와 검증 상태

문제는 별도로 제작된 `quiz_1230_ko.json`(데이터 버전 `2026-11-10.1`)을 변환해 사용합니다. 각 문항은 원본의 ID·분류·보기·정답·해설·출처(URL, 기록 위치)·검증 상태를 그대로 유지합니다. 원본에 없는 문항별 난이도 수치와 추가 배경 지식은 임의로 만들어 넣지 않았습니다.

- 1,230문항 모두 `source_record_checked`: 출처 기록과 핵심 사실을 기계적으로 대조한 상태입니다.
- 1,230문항 모두 `pending_full_human_review`: **사람이 전체 문항을 읽고 최종 승인하는 전수 검수는 아직 끝나지 않았습니다.** 앱의 해설 영역과 설정 화면에 이 상태를 그대로 표시합니다.

자세한 자동 검증 결과는 [VALIDATION.md](VALIDATION.md)에 있습니다.

## 실행·검증

```bash
python -m http.server 8000        # http://localhost:8000
node scripts/validate.mjs         # 데이터 검증
node --test tests/                # 엔진 테스트
node scripts/import-source.mjs "<경로>/quiz_1230_ko.json"   # 데이터 갱신
```

데이터를 갱신할 때 기존 ID를 유지하면 사용자의 출제 기록·오답 노트가 그대로 이어집니다. 데이터를 바꾼 뒤에는 `sw.js`의 `VERSION`을 올려 캐시를 갱신하세요.
